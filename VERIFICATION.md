## Error boundary

`main.ts` reports every input problem on one line and exits `2`; it never prints a stack trace for them:

| Case | Output | Exit |
|---|---|---:|
| `node main.ts` (no `--input`, no `/input`) | `token radar: no snapshot at /input/snapshot.json: pass --input <snapshot.json\|directory> or mount the sealed /input` | `2` |
| `--input <path that does not exist>` | `token radar: no snapshot at <path>: pass --input <snapshot.json\|directory> or mount the sealed /input` | `2` |
| a snapshot that is not JSON | `token radar: <path> is not a usable snapshot: snapshot is not JSON: …` | `2` |
| a snapshot with a missing or wrong field | `token radar: <path> is not a usable snapshot: protocols[0].name is not a non-empty string` (field named) | `2` |

A board that breaks the gate's shape (`boardIssue` not null) or screenshots that are missing or badly named exit `1` with one line of reason.
